# Enterprise Skills — always on

Before any task, check which of these skills apply and load them with the Skill tool. Apply every relevant one; say which you used.

| Skill | Use for |
|---|---|
| ux-design | Any UI, flow, form, copy |
| accessibility | Any UI code (WCAG 2.2 AA) |
| security | Auth, input, data, APIs, secrets, reviews |
| privacy-compliance | Personal data, analytics, audit logs, tenancy |
| testing-quality | Features, bug fixes, refactors, reviews |
| performance-reliability | Pages, queries, jobs, deploys |
| api-architecture | Endpoints, schemas, services, integrations |
| ai-features | Any LLM/AI feature or prompt |
| user-research | Planning, validating, analyzing feedback |
| marketing-growth | Landing pages, launch, onboarding, pricing |

Code changes always apply **security** and **testing-quality** at minimum.
